Hi there! This is the first among several projects that help me learn and exercise industry standard Java development practices.

It's a Student Management System that allows users to manage student registration in a school setup via JDBC and regular CRUD operations with a POSTGRESQL db.

KEY FOCUS AREAS
* Proper project setup and SOLID principles
* Basic, clean, exception handling
* Using maven as a build tool and dependency manager
* Connect to a database with bare metal JDBC and a frontend that is NOT JFX
